# Checkout — UX

The renter already decided what the room is. This screen only asks how long, where, and who.

## Path

1. Open from Review rental (or the Review link).
2. See the same room, smaller, plus a line per chosen piece and a total for the term.
3. If the desk or the chair is missing, do not show the form. Say what is missing and link straight back to that category.
4. If both are present: weeks (stepper, default 4, range 1–52), Bali area, name, email, one button: **Rent this setup**.
5. Success replaces the form with a request id and the total. **Design another setup** clears the room and returns to the studio.
6. A bad field comes back next to that field, with one banner. A network failure is the same banner and the form stays so they can retry. No second error page.

## What we refuse to add

- Payment fields. There is no processor in this preview. Say that plainly.
- A second summary screen after success. The confirmation is this screen.
